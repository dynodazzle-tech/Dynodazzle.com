# Vikas Yadav — The Series

A responsive, single-file HTML/CSS/vanilla JavaScript portfolio.

## Files
- `index.html` — complete portfolio site
- Add `photo.jpg` beside `index.html` for the portrait
- Add `Vikas_Yadav_Updated_CV.pdf` beside `index.html` for the resume download

Project links are configured in the `DATA` object near the top of the JavaScript in `index.html`.

Hosted on Vercel as a static site.
